# Artes das cartas

Coloque aqui as imagens das cartas. Cada arquivo substitui a ilustração desenhada do personagem correspondente.

| Arquivo | Carta |
|---|---|
| `banqueiro.png` | Banqueiro (Cobrar Juros: +3 moedas, bloqueia Ajuda Externa) |
| `envenenador.png` | Envenenador (paga 3, o alvo perde uma influência) |
| `contrabandista.png` | Contrabandista (toma 2 moedas, bloqueia Saque) |
| `emissario.png` | Emissário (troca cartas com a Corte, bloqueia Saque) |
| `alquimista.png` | Alquimista (bloqueia Envenenar) |
| `verso.png` | Verso de todas as cartas |

- Formatos aceitos: `.png`, `.webp`, `.jpg`, `.jpeg` ou `.svg` (o jogo procura nessa ordem).
- Proporção ideal: **5 × 7** (ex.: 500 × 700 px). Outras proporções são cortadas para caber.
- A imagem ocupa a carta inteira, então inclua o nome e a moldura na própria arte.
- Pode colocar só algumas: as que faltarem continuam com o desenho padrão.
- Depois de trocar uma imagem, recarregue a página (Ctrl+F5 se o navegador guardar a antiga).
